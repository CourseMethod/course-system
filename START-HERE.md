# Start here

**Five minutes. Read this before anything else.**

---

## What you just got

Two things, and it matters that you understand they are separate:

**1. A course** (`vault/`) — 40 lessons that teach you how to build and sell a digital
course. Open it in Obsidian. This is the part you *read*.

**2. A selling system** (`web/` + `backend/`) — the sales page, checkout, automatic
delivery, customer database and admin dashboard. This is the part you *run*. It is the
same system that sold you this.

You do not need both at once. Most people should start with the first.

---

## The five-minute version

### If you want to read the course (start here)

```
1. Install Obsidian — obsidian.md, free
2. Open it → "Open folder as vault" → select the `vault/` folder
3. Open 00-Command-Center.md
4. Follow what it says
```

That is genuinely it. Nothing to install, nothing to configure.

**Do not read all 40 lessons first.** The Command Center explains why, and it is the
single most important instruction in the whole system.

### If you want to run the selling system

Only once you have something to sell. But if you want to see it work locally:

```bash
cd backend
npm install
cp .env.example .env
npm run check-env      # tells you exactly what's missing
npm start
```

Then open http://localhost:3000. It runs with no Stripe keys and no email setup — emails
print to your terminal instead of sending. See `SETUP.md` for the real thing.

## The order to do things in

This is the part people get wrong, so it is worth being blunt:

| Order | Do this | Roughly |
|-------|---------|---------|
| 1 | Read Module 1. Pick your topic. | 1 week |
| 2 | Read Module 2. **Write your course.** | 2–4 weeks |
| 3 | *Start posting while you write* (Module 4) | ongoing |
| 4 | Read Module 3. Set up selling. | 1 weekend |
| 5 | Launch. Keep posting. | months |

**Do not do step 4 first.** Building the sales machine before the product exists is the
most seductive way this fails — it is visible, satisfying, measurable work, and at the end
you have a beautiful checkout for a course nobody wrote.

## What this is not

Being straight with you up front, because the category has earned its reputation:

- **Not passive income.** Forty to eighty hours before you earn anything.
- **Not fast.** Weeks to build. Months to distribute.
- **Not guaranteed.** Nothing here promises you will earn a specific amount, because
  nobody honestly can. It depends on your topic, your audience and how long you keep
  going.
- **Not a get-rich scheme.** It is a way to package knowledge you already have and sell it
  without a platform taking a cut.

If you were hoping otherwise, better to know now.
