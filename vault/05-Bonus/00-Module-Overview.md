# Module 5 — Beyond the first launch

**5 lessons · about 55 minutes · for after you have sales**

---

## Who this is for

You have launched. You have made some sales — not many, necessarily, but enough that the
thing works.

This module is about turning an event into a business: what to build next, how to charge
more without losing buyers, how to get other people selling for you, how to collect proof
legally, and how to make it run without consuming every evening.

**If you have not launched yet, skip this module entirely.** Reading it now will generate
plans that distract from the work that matters, which is finishing and posting.
